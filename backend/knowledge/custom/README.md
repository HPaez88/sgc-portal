# Carpeta de Documentación Personalizada para el Agente ISO

Coloca en esta carpeta cualquier archivo de texto (`.txt`, `.md`, `.json`) o normativa interna adicional que desees que el **Agente Normativo ISO** indexe y consulte.

### Estructura sugerida para archivos Markdown/Texto:
- Incluye el título del documento o norma.
- Identifica las cláusulas o apartados con números (ej. `## 4.1 Requisito...`).
- Describe los criterios obligatorios y la evidencia que solicitas para su cumplimiento.

El agente consultará **exclusivamente** esta documentación junto con las normas oficiales ISO para darte la mejor interpretación y resolución ante auditorías.
